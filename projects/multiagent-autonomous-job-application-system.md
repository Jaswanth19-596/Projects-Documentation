### 2. Worker unexpectedly stopping
*Aug 21, 2026, 04:08 PM* | Category: coding

The worker is stopping all of a sudden and returning the control to the manager. 

How to solve this: 
Agent works in the following way:
1. Agent thinks.
2. Calls tool.
3. Tool Result.
4. Agent's turn.
5. At the end, worker returns response.

One of the following can be the issues:
1. Worker produces response, but manager rejects it -> Prompt/output-schema or parser issue.

2. Model produces invalid/non-terminal response -> Prompt/ terminal status validation issue.

3. Tool call returns an error, then worker ends -> Tool handling / recovery logic issue.

4. Tool call succeeds, but there is no subsequent model response -> Model API, stream, cancellation process, runtime issue.

5. Repeated thought/tool calls until a recursion limit -> Control loop issue, prompting may be contributing to the loop.

6. Process exits or gets a signal -> Time out, Cancellation
