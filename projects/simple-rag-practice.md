## Learnings

- **approach:** Loading the Documents

  Each page of the PDF is treated as a single document.

- **approach:** QdrantVectorStore, StorageContext and VectorStoreIndex

  QdrantVectorStore : It is just the database connection. We just tell it which qdrant instance and which collection to talk to. 

StorageContext : Answers, where do i store the vectors.
- From default : Use all the defaults, but override what i pass in.

A storage context has multiple parameters:
- A vector store : Which stores vectors.
- A document store : Which stores documents (chunks).
- A Index store : Which stores the metadata.
- A kv_store : Other key value type of data.
- A graph store: Used when building knowledge graphs. 

VectorStoreIndex: When you call from_documents():
- It takes raw documents, chunks them and runs them through the embedding model to convert each chunk to a vector.
- Passes those embeddings down to storage context which writes them into the qdrant vector store.
