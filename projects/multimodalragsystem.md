    - image_embeds : Embeddings of the image.

- **skill:** Forward methods of CLIP

  CLIP has three forward methods:
1. model(**inputs) : Requires both text and images.
2. model.get_image_features(**inputs) : Images only.
3. model.get_text_features(**inputs) : Text only.

- **skill:** Clip's Architecture

  CLIP has two encoders - One for text, one for images. Each encoder outputs embeddings in it's own internal space.
    - Text Encoder (BERT like transformer) -> outputs vectors of size 512.
    - Vision Encoder (ViT) -> outputs vectors of size 768.

These two spaces are completely different and incomparable. You can't directly compare a text vector to an image vector at this stage.

The Projection Head:
To fix this, CLIP adds a small linear projection layer on top of each encoder that maps both outputs into a shared space of size 512.

    - get_text_features and get_image_features return BaseModelOutputWithPooling which is the raw encoder output, not in the shared space.

    - model(**inputs).text_embeds and model(**inputs).image_embeds -> These are the projected embeddings in the shared 512 dim space, directly comparable to each other.
